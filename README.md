Projekt sygnalizacji świetlnej skrzyżowania

Projekt automatycznego sterowania sygnalizacją świetlną skrzyżowania wykonany w środowisku CODESYS.

Sterowanie ruchem odbywa się poprzez załączanie naprzeciwległych kierunków.
System monitoruje liczbę pojazdów oczekujących na poszczególnych kierunkach.
Na podstawie natężenia ruchu sterownik dynamicznie dostosowuje czas trwania zielonego światła.
Projekt zawiera również symulację ruchu pojazdów oraz podstawową diagnostykę stanów sygnalizacji.
